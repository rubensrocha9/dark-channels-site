Dark Channels Studio

Dark Channels Studio is a private desktop tool used by one independent creator to produce documentary-style videos about history and science for their own YouTube channels.

What it does

  1. Researches a topic in public sources and writes a narration script.
  2. Generates the narration with text-to-speech and assembles images: freely licensed photos from Wikimedia Commons and AI-generated illustrations.
  3. Renders the final MP4, which the creator watches and approves by hand.
  4. Uploads the approved video to the creator's own YouTube channel, with the title, description, tags, privacy status and publish date the creator chooses, and discloses AI-generated content.

Uses YouTube API Services

This application uses YouTube API Services (YouTube Data API v3) to upload videos and to list the creator's own uploads. By using it you agree to the YouTube Terms of Service. See our Privacy Policy and the Google Privacy Policy.

The tool is not offered to the public, sold or distributed. It runs only on the creator's computer.
