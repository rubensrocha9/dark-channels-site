Privacy Policy

Dark Channels Studio · Last updated: October 30, 2026

YouTube API Services

Dark Channels Studio uses YouTube API Services (YouTube Data API v3). By using it, you are also bound by the Google Privacy Policy and agree to the YouTube Terms of Service.

Who uses this application

Dark Channels Studio is a private desktop tool. Its only user is the creator who operates it, signing in with their own Google account to manage their own YouTube channels. It does not access data of any other YouTube user.

What data we access

When the creator signs in with Google (OAuth 2.0), the application requests two permissions:

  • youtube.upload: to upload videos the creator has approved, with the title, description, tags, privacy status and publish date the creator chooses.
  • youtube.readonly: to list the creator's own uploaded videos, so the tool can confirm an upload finished and never uploads the same video twice.

What data we store and how we use it

  • The OAuth access and refresh tokens, stored only in a local file on the creator's computer, outside any code repository and logs.
  • For each video produced, the YouTube video ID, title and upload date, stored in the same local project folder as the video.

This data is used only to upload and track the creator's own videos. We do not use cookies, analytics or advertising, and we do not run any server that receives YouTube data.

Sharing

We do not sell, share or disclose any YouTube API data to third parties. Topic research and script writing use external AI services, which receive only the topic text and public research sources, never YouTube data or account information.

Retention and deletion

  • Tokens are kept only while the creator keeps the account connected. Disconnecting the account in the application deletes the token file.
  • Stored YouTube data (video IDs and titles) is deleted together with the production folder, and is refreshed or deleted within 30 days as required by the YouTube API Services policies.
  • You can revoke this application's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • To ask for deletion of any stored data, write to the contact below. We will delete it within 7 days.

Changes

Any change to this policy will be published on this page with a new date.
